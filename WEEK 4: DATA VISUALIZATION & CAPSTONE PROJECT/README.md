# WEEK 4: DATA VISUALIZATION & CAPSTONE PROJECT

## Project: End-to-End Sales Analysis

This project was completed as part of Week 4 of my Data Analyst Internship.

The project focuses on an end-to-end sales analysis workflow, starting from data cleaning and exploratory analysis in Python and Pandas, followed by business analysis, Excel visualization, Power BI dashboard development, and final business insights and recommendations.

---

## Project Objectives

- Clean and validate the dataset using Python and Pandas
- Perform Exploratory Data Analysis (EDA)
- Analyze sales and profit using Pandas
- Identify important business patterns and trends
- Create an Excel dashboard for sales performance analysis
- Build an interactive Power BI dashboard
- Summarize key findings and provide business recommendations
- Compile a final project report

---

## Tools Used

- Python
- Pandas
- Excel
- Power BI

---

## Dataset

The cleaned dataset contains:

- **700 records**
- **16 columns**
- **0 duplicate records after cleaning**
- **0 missing values after cleaning**
- **Analysis period:** September 2013 – December 2014

During data cleaning, 53 records had a missing `Discount Band` and a `Discount` value of 0. These records were classified as **No Discount** based on the assumption that a zero discount indicates that no discount was applied.
